# College Events Management System

A PHP and MySQL-based web application designed to simplify college event management.

## Features

- User authentication
- Event creation and management
- Student event registration
- Attendance tracking
- Team registration
- Participant management
- Event dashboard
- MySQL database integration

## Technologies Used

- PHP
- MySQL
- HTML
- CSS
- JavaScript
- MAMP
- Git and GitHub

## Project Structure

- `app/` – Application models, authentication, and database files
- `assets/` – CSS and JavaScript files
- `public/` – Main application pages and APIs
- `views/` – Reusable page components
- `schema.sql` – Database structure

## How to Run

1. Install and open MAMP.
2. Place the project inside:

   `/Applications/MAMP/htdocs/myproject/`

3. Start Apache and MySQL in MAMP.
4. Create a database using `schema.sql`.
5. Update database credentials in the configuration file.
6. Open the project through the MAMP localhost URL.
